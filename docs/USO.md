# Uso rápido

1. Abrí el editor.
2. Configurá el nombre, descripción, WhatsApp y moneda.
3. Elegí un tema.
4. Creá categorías.
5. Cargá productos y fotografías.
6. Abrí **Vista previa**.
7. Exportá el proyecto si querés una copia portable.
8. Para publicar, ejecutá `Subir_CatalogoFacil.bat`.

El catálogo del cliente permite seleccionar productos y preparar el pedido para WhatsApp.


PUBLICACION V23: SUBIR_A_GITHUB.bat pide la URL del repositorio y usa la autorizacion incluida en el BAT; no pide el token en cada ejecucion.
